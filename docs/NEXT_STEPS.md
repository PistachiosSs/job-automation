## v0.2 priorities

1. **ChatGPT-to-app bridge:** Determine eligibility for a custom ChatGPT app/MCP server. A local-only server is not directly reachable from ChatGPT cloud; a user-approved secure remote endpoint or other supported integration is necessary. Avoid public unauthenticated exposure of CVs.
2. **Google Sheets:** Set up authorized Google Sheets MCP or OAuth API. Create a new Google Sheet, map the existing CSV schema, and write/upsert by application ID after explicit approvals. Do not claim Sheets are synchronized before a successful authenticated write.
3. **Better LaTeX validation:** Validate text-only changes against the template's macro and environment scaffold; add optional page-count and overflow warnings.
4. **Revision history:** Snapshot every edit/compilation so users can undo individual AI edits.
5. **Cover letter:** Test its actual compilation and style preservation once the missing source arrives.
